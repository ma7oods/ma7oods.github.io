yutuMa7oods

A private desktop tool that Balbol uses to manage its own YouTube channels.

What it does

yutuMa7oods runs on the owner's own Windows computer. After the owner signs in with Google and picks one of his own YouTube channels, the tool can do these things on that channel, and only when he asks for them:

  • Upload videosSend a finished video file to the channel as private, public or scheduled.
  • Edit video detailsSet the title, description, tags and thumbnail of the channel's own videos.
  • Organise playlistsCreate playlists and add the channel's videos to them.
  • Read channel numbersShow the channel's video list with its views, likes and subscriber count.

Who can use it

Only its owner. The tool is not offered to the public, has no sign-up and no website login, and is used only with the owner's own Google account and YouTube channels.

How it works

The tool is the open-source yutu command-line program, connected to the YouTube Data API v3 through Google sign-in (OAuth 2.0). It has no server of its own: requests go directly from the owner's computer to Google, and the sign-in token is kept in a file on that computer.
